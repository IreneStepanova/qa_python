Тесты
1.	Добавление двух книг в словарь books_genre
* Метод: add_new_book
* ОР: Добавилось 2 книги в словать
2.	Книга не добавляется, если название содержит пустое значение, 41 символ и больше 40 символа
* Метод: add_new_book

* ОР: Книга, название которой содержит пустое значение, 41 символ и больше 40 символа, не добавляется в словарь books_genre.
3.	Книга не добавляется повторно
* Метод: add_new_book
* ОР: При повторной попытке добавить одну и ту же книгу, она не добавляется
4.	Установка жанра для существующей книги
* Метод: set_book_genre
* ОР: Существующей книге присваивается жанр из разрешённого списка.
5.	Получение жанра сущесвтвующей книги
* Метод: get_book_genre
* ОР: Метод возвращает жанр указанной книги.

6. Получение списка книг с определенным жанром
* Метод: get_books_with_specific_genre
* ОР: Метод возвращает список книг с определенным жанром

7. Возвращение словаря
* Метод: get_books_genre
* ОР: Метод возвдащает словарь

8. Искелючение книг без жанра из списка для детей
* Метод: get_books_for_children
* ОР: Книги без жанра не попадают в спислк для детей

9. Добавление книги в избранное
* Метод: add_book_in_favorites
* ОР: Книга добавляется в список favorites, если она есть в books_genre.

10. Удаление книги из избранного
* Метод: delete_book_from_favorites
* ОР: Книга удаляется из списка favorites, если ранее была туда добавлена

11. Возвращение списка книг из Избранного
* Метод: get_list_of_favorites_books
* ОР: Метод возвращает список книг из Избранного
